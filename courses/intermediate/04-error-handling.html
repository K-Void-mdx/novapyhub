Lesson 4: Error Handling and Exceptions

What are Exceptions?

Exceptions are errors that occur during program execution. Instead of crashing your program, you can catch and handle them gracefully.

Common Exception Types

<code># ZeroDivisionError
print(10 / 0)  # ZeroDivisionError: division by zero

# ValueError
int("hello")  # ValueError: invalid literal for int()

# TypeError
"5" + 3  # TypeError: can only concatenate str (not "int") to str

# IndexError
nums = [1, 2, 3]
print(nums[10])  # IndexError: list index out of range

# KeyError
person = {"name": "Alice"}
print(person["age"])  # KeyError: 'age'

# FileNotFoundError
open("nonexistent.txt")  # FileNotFoundError</code>

Try/Except Blocks

<code>try:
    number = int(input("Enter a number: "))
    result = 10 / number
    print(f"Result: {result}")
except ValueError:
    print("Please enter a valid number!")
except ZeroDivisionError:
    print("Cannot divide by zero!")</code>

Catching Multiple Exceptions

<code># Multiple except blocks
try:
    num = int(input("Enter a number: "))
    result = 100 / num
    print(result)
except (ValueError, ZeroDivisionError):
    print("Invalid input or division by zero!")

# Catching all exceptions (use carefully!)
try:
    x = int("hello")
except Exception as e:
    print(f"An error occurred: {e}")</code>

Else and Finally

else runs if no exception occurred. finally always runs:

<code>try:
    num = int(input("Enter a number: "))
    result = 100 / num
except ValueError:
    print("Not a number!")
except ZeroDivisionError:
    print("Can't divide by zero!")
else:
    print(f"Result: {result}")  # Runs only if no error
finally:
    print("This always runs.")  # Cleanup code</code>

Raising Exceptions

You can manually raise exceptions with raise:

<code>def withdraw(balance, amount):
    if amount <= 0:
        raise ValueError("Amount must be positive!")
    if amount > balance:
        raise ValueError("Insufficient funds!")
    return balance - amount

try:
    new_balance = withdraw(100, 150)
except ValueError as e:
    print(f"Error: {e}")

# Re-raising
def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("Logging error...")
        raise  # Re-raise the same exception</code>

Creating Custom Exceptions

<code>class InsufficientFundsError(Exception):
    """Raised when account balance is insufficient."""
    pass

class NegativeAmountError(Exception):
    """Raised when amount is negative."""
    def __init__(self, amount):
        self.amount = amount
        super().__init__(f"Amount cannot be negative: {amount}")

def transfer(balance, amount):
    if amount < 0:
        raise NegativeAmountError(amount)
    if amount > balance:
        raise InsufficientFundsError("Not enough money!")
    return balance - amount

try:
    transfer(500, -50)
except NegativeAmountError as e:
    print(e)
except InsufficientFundsError as e:
    print(e)</code>

Assertions

Use assert for debugging — it raises AssertionError if the condition is False:

<code>def calculate_bmi(weight, height):
    assert weight > 0, "Weight must be positive"
    assert height > 0, "Height must be positive"
    return weight / (height ** 2)

# Can be disabled with -O flag when running Python</code>

Best Practices

  • Catch specific exceptions, not generic Exception
  • Don't hide errors with empty except blocks
  • Use finally for cleanup (closing files, releasing resources)
  • Log exceptions rather than just printing them
  • Raise exceptions early when detecting invalid state

Practice Exercises

  3. Create a custom exception class for a bank account system
  4. Write a program that keeps asking for a valid number until one is entered
  5. Use try/except/else/finally to demonstrate all four blocks working
