Lesson 2: List Comprehensions and Generator Expressions

What are List Comprehensions?

List comprehensions provide a concise way to create lists. Instead of writing a for loop with append(), you can do it in one line.

Basic List Comprehension

# Traditional way
squares = []
for x in range(10):
    squares.append(x ** 2)
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# List comprehension (same result)
squares = [x ** 2 for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

Syntax Pattern

[expression for item in iterable if condition]

With Conditionals

# Even squares only
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]
print(even_squares)  # [0, 4, 16, 36, 64]

# If-else in expression
labels = ["even" if x % 2 == 0 else "odd" for x in range(5)]
print(labels)  # ['even', 'odd', 'even', 'odd', 'even']

Nested Loops in Comprehensions

# Flatten a matrix
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [num for row in matrix for num in row]
print(flat)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# Multiplication table
pairs = [(i, j) for i in range(1, 4) for j in range(1, 4)]
print(pairs)
# [(1, 1), (1, 2), (1, 3), (2, 1), (2, 2), (2, 3), (3, 1), (3, 2), (3, 3)]

Practical Examples

# Convert strings to uppercase
names = ["alice", "bob", "charlie"]
upper_names = [name.upper() for name in names]
print(upper_names)  # ['ALICE', 'BOB', 'CHARLIE']

# Extract emails from list of dicts
users = [
    {"name": "Alice", "email": "alice@email.com"},
    {"name": "Bob", "email": "bob@email.com"}
]
emails = [user["email"] for user in users]
print(emails)  # ['alice@email.com', 'bob@email.com']

# Remove vowels from text
text = "hello world"
no_vowels = "".join(c for c in text if c not in "aeiou")
print(no_vowels)  # "hll wrld"

Generator Expressions

Generator expressions use () instead of [] and produce items lazily (one at a time), saving memory:

# List comprehension — creates the entire list in memory
squares_list = [x ** 2 for x in range(1000)]

# Generator expression — produces items on demand
squares_gen = (x ** 2 for x in range(1000))

print(type(squares_list))  # 
print(type(squares_gen))   # 

# Using a generator
for x in squares_gen:
    print(x)
    if x > 10:  # Only generates what we need
        break

# Generator as function argument
total = sum(x ** 2 for x in range(10))
print(total)  # 285 (sum of squares 0-9)

Dict Comprehensions

# Create a dictionary mapping numbers to their squares
squares_dict = {x: x ** 2 for x in range(5)}
print(squares_dict)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# Invert a dictionary
original = {"a": 1, "b": 2, "c": 3}
inverted = {v: k for k, v in original.items()}
print(inverted)  # {1: 'a', 2: 'b', 3: 'c'}

Set Comprehensions

# Get unique squares modulo 5
unique = {x ** 2 % 5 for x in range(20)}
print(unique)  # {0, 1, 4}

# Extract unique first letters
names = ["Alice", "Bob", "Charlie", "Anna"]
first_letters = {name[0] for name in names}
print(first_letters)  # {'A', 'B', 'C'}

When NOT to Use List Comprehensions

Keep it readable. If the logic is complex, use a regular loop:

# Too complex — hard to read
result = [func(x) for x in data if check(x) for y in x if y > 0]

# Better as regular loop
result = []
for x in data:
    if check(x):
        for y in x:
            if y > 0:
                result.append(func(x))
