Lesson 7: Working with Modules and Packages

Learn to organize code into modules and packages, manage imports, and use pip for third-party packages.

Creating Packages

A package is a folder with an __init__.py file containing multiple modules:

my_package/
    __init__.py
    math_ops.py
    string_ops.py

Import Types

import my_package.math_ops
from my_package import math_ops
from my_package.math_ops import add, subtract

Using pip

pip install requests
pip install numpy pandas matplotlib
pip freeze > requirements.txt

Practice

  1. Create a package with 3 modules and import them in different ways
  2. Install requests and make a GET request to an API
  3. Create a requirements.txt for a project
