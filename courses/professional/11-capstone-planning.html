Lesson 11: Capstone Project — Planning & Design

Design a full-stack application from scratch. This is the culmination of everything you've learned.

Project Idea: Task Management API

Build a complete task management system with:

Requirements

  • User registration and authentication (JWT)
  • CRUD operations for tasks
  • Task categories and tags
  • Search and filter tasks
  • RESTful API with FastAPI
  • SQLite/PostgreSQL database
  • Unit and integration tests
  • Docker containerization
  • CI/CD pipeline

Architecture

task_manager/
├── app/
│   ├── __init__.py
│   ├── main.py          # FastAPI app
│   ├── models.py        # SQLAlchemy models
│   ├── schemas.py       # Pydantic schemas
│   ├── crud.py          # Database operations
│   ├── auth.py          # JWT authentication
│   └── dependencies.py  # Dependency injection
├── tests/
│   ├── test_api.py
│   └── test_models.py
├── Dockerfile
├── requirements.txt
└── README.md

Database Schema

User: id, username, email, hashed_password, created_at
Task: id, title, description, status, priority, user_id (FK), category_id (FK), created_at, updated_at
Category: id, name, user_id (FK)

Your task this lesson is to design the complete system and start implementing models and schemas.
