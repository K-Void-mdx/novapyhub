Lesson 12: Capstone Project — Build & Deploy

Implement, test, and deploy your capstone project to production.

Implementation Steps

  1. Set up FastAPI project structure
  2. Implement database models (SQLAlchemy)
  3. Create Pydantic schemas for validation
  4. Implement CRUD operations
  5. Add JWT authentication
  6. Write tests (unit + integration)
  7. Dockerize the application
  8. Set up CI/CD with GitHub Actions
  9. Deploy to Render/Railway/Fly.io

Starting Code

# app/main.py
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI(title="Task Manager API")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/")
def root():
    return {"message": "Task Manager API"}

@app.get("/health")
def health():
    return {"status": "healthy"}

Deployment Checklist

  • Set environment variables (DATABASE_URL, SECRET_KEY)
  • Use gunicorn + uvicorn for production
  • Add database migration system (Alembic)
  • Set up monitoring and logging
  • Configure domain and SSL
