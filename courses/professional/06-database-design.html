Lesson 6: Database Design and SQL

Professional database design: normalization, indexes, transactions, and optimization.

Normalization (3NF)

  • 1NF: Each column has atomic values, no repeating groups
  • 2NF: 1NF + all non-key columns depend on the full primary key
  • 3NF: 2NF + no transitive dependencies

Indexes

-- CREATE INDEX idx_users_email ON users(email);
-- Indexes speed up SELECT but slow down INSERT/UPDATE

Transactions

import sqlite3
conn = sqlite3.connect("bank.db")
cursor = conn.cursor()

try:
    conn.execute("BEGIN")
    cursor.execute("UPDATE accounts SET balance = balance - 100 WHERE id = 1")
    cursor.execute("UPDATE accounts SET balance = balance + 100 WHERE id = 2")
    conn.commit()  # Both succeed or both fail
except:
    conn.rollback()  # Revert all changes

JOIN Types

-- INNER JOIN: only matching rows
-- LEFT JOIN: all from left, NULLs on right
-- RIGHT JOIN: all from right, NULLs on left
-- FULL OUTER JOIN: all from both

SELECT u.name, o.amount
FROM users u
JOIN orders o ON u.id = o.user_id
