Lesson 3: Strings and Text Processing

Creating Strings

Strings are sequences of characters. You can create them with single or double quotes:

<code>name = 'Alice'
message = "Hello, World!"
multiline = """This is a
multi-line string."""</code>

String Concatenation

Combine strings with +:

<code>first = "John"
last = "Doe"
full = first + " " + last
print(full)  # John Doe</code>

String Repetition

Repeat strings with *:

<code>line = "-" * 50
print(line)  # Prints 50 dashes

echo = "Hello! " * 3
print(echo)  # Hello! Hello! Hello!</code>

String Indexing

Each character in a string has an index (position), starting from 0:

<code>text = "Python"
#      P y t h o n
#      0 1 2 3 4 5

print(text[0])  # P
print(text[3])  # h
print(text[-1]) # n (last character)
print(text[-2]) # o (second from last)</code>

String Slicing

Extract parts of a string using [start:end:step]:

<code>text = "Python Programming"

print(text[0:6])      # "Python" (start to index 5)
print(text[7:18])     # "Programming"
print(text[:6])       # "Python" (from start)
print(text[7:])       # "Programming" (to end)
print(text[::2])      # "Pto rgamn" (every 2nd char)
print(text[::-1])     # "gnimmargorP nohtyP" (reversed!)</code>

String Methods

Python provides many built-in string methods:

<code>text = "  Hello, Python World!  "

print(text.lower())          # "  hello, python world!  "
print(text.upper())          # "  HELLO, PYTHON WORLD!  "
print(text.strip())          # "Hello, Python World!" (removes spaces)
print(text.replace("Python", "Code"))  # "  Hello, Code World!  "

# Finding and counting
print(text.find("Python"))   # 9 (index where "Python" starts)
print(text.count("o"))       # 3 (how many times "o" appears)

# Checking content
print("Hello".startswith("He"))  # True
print("Hello".endswith("lo"))    # True
print("abc123".isalpha())        # False (has numbers)
print("abc".isalpha())           # True
print("123".isdigit())           # True</code>

String Formatting

There are several ways to format strings. F-strings (Python 3.6+) are the best:

<code>name = "Alice"
age = 25
score = 92.5

# F-strings (recommended)
print(f"My name is {name} and I am {age} years old.")
print(f"Score: {score:.1f}%")  # "Score: 92.5%"

# .format() method
print("My name is {} and I am {} years old.".format(name, age))

# % formatting (older style)
print("My name is %s and I am %d years old." % (name, age))</code>

Escape Sequences

Special characters in strings use backslash \:

<code>print("Line 1\nLine 2")     # New line
print("Tab\tseparated")     # Tab
print("She said \"Hello\"") # Double quote inside string
print("Backslash: \\")      # Actual backslash
print(r"Raw string \n")     # Raw string (ignores escape)</code>

len() Function

Get the length of a string with len():

<code>text = "Hello"
print(len(text))  # 5</code>
