Lesson 8: Functions Basics

What is a Function?

A function is a reusable block of code that performs a specific task. Functions help you organize code, avoid repetition, and make your programs easier to read and maintain.

Defining and Calling Functions

# Define a function
def greet():
    print("Hello!")
    print("Welcome to Nova Py-Hub!")

# Call the function
greet()
greet()

Function Parameters

Pass data into functions using parameters:

def greet(name):
    print(f"Hello, {name}!")

greet("Alice")  # Hello, Alice!
greet("Bob")    # Hello, Bob!

Multiple Parameters

def introduce(name, age, city):
    print(f"I'm {name}, {age} years old, from {city}.")

introduce("Alice", 25, "New York")
introduce(city="London", name="Bob", age=30)  # Keyword arguments

Return Values

Functions can return results using return:

def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # 8

# Multiple return values
def get_min_max(numbers):
    return min(numbers), max(numbers)

low, high = get_min_max([3, 1, 7, 2, 9])
print(f"Low: {low}, High: {high}")

Default Parameters

def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")          # Hello, Alice!
greet("Bob", "Hi")      # Hi, Bob!
greet("Charlie", "Hey")  # Hey, Charlie!

Scope — Local vs Global Variables

# Global variable
message = "Hello"

def greet(name):
    # Local variable
    greeting = f"{message}, {name}!"
    print(greeting)

greet("Alice")  # Hello, Alice!
print(message)  # Works (global)
# print(greeting)  # Error! (local variable)

Docstrings

Document what your function does with a docstring:

def calculate_bmi(weight, height):
    """Calculate BMI given weight (kg) and height (m)."""
    return weight / (height ** 2)

print(calculate_bmi(70, 1.75))
print(calculate_bmi.__doc__)  # Access the docstring

Function Examples

# Check if a number is even
def is_even(n):
    return n % 2 == 0

print(is_even(4))   # True
print(is_even(7))   # False

# Convert temperature
def celsius_to_fahrenheit(c):
    return (c * 9/5) + 32

print(celsius_to_fahrenheit(0))    # 32.0
print(celsius_to_fahrenheit(100))  # 212.0

# Validate password length
def is_valid_password(password):
    return len(password) >= 8

print(is_valid_password("short"))      # False
print(is_valid_password("longenough")) # True
