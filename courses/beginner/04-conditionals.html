Lesson 4: Conditional Statements

What are Conditionals?

Conditional statements let your program make decisions. They execute different code based on whether a condition is True or False.

The if Statement

The simplest conditional: if the condition is True, the indented code runs:

age = 18

if age >= 18:
    print("You are an adult.")
    print("You can vote!")

print("This always runs.")

Important: Python uses indentation (4 spaces) to define blocks of code.

Comparison Operators

==    # Equal to
!=    # Not equal to
<     # Less than
>     # Greater than
<=    # Less than or equal to
>=    # Greater than or equal to
x = 10
print(x == 10)   # True
print(x != 5)    # True
print(x > 20)    # False
print(x <= 10)   # True

if-else Statements

Run one block if True, another if False:

temperature = 30

if temperature > 25:
    print("It's hot outside!")
else:
    print("It's cool outside.")

if-elif-else Chains

For multiple conditions, use elif (short for "else if"):

score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Your grade is: {grade}")

Logical Operators

Combine multiple conditions with and, or, and not:

age = 22
has_license = True

# Both conditions must be True
if age >= 18 and has_license:
    print("You can drive!")

# At least one must be True
if age < 12 or age > 80:
    print("Special rate applies.")

# Negate a condition
if not has_license:
    print("You need a license to drive.")

The in Operator

Check if a value exists in a collection:

fruits = ["apple", "banana", "orange"]
if "banana" in fruits:
    print("Banana is in the list!")

name = "David"
if "Dav" in name:
    print("Name contains 'Dav'")

Truthy and Falsy Values

In Python, some values are considered "falsy" (False-like):

# These are FALSY:
bool(0)       # False
bool("")      # False (empty string)
bool([])      # False (empty list)
bool(None)    # False (none)
bool(False)   # False

# Everything else is TRUTHY:
bool(1)       # True
bool("abc")   # True
bool([1, 2])  # True

# Useful pattern:
name = ""
if name:  # Only runs if name is not empty
    print(f"Hello, {name}!")
else:
    print("Name is empty!")

Nested Conditionals

You can put conditionals inside conditionals:

age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Welcome to the concert!")
    else:
        print("You need a ticket.")
else:
    print("You are too young.")

Practice Exercises

  1. Write a program that checks if a number is positive, negative, or zero
  2. Create a simple login system: ask for a username and password, check if they match stored values
  3. Write a program that tells someone if they can ride a roller coaster (height >= 120cm AND age >= 10)
  4. Use and/or/not to check if a number is between 10 and 20 (inclusive)
