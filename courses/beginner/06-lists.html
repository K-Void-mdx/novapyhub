Lesson 6: Lists and Tuples

What is a List?

A list is an ordered, mutable collection of items. Lists can hold items of any type, and you can change them after creation.

# Creating lists
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]
empty = []
nested = [[1, 2], [3, 4]]

Accessing List Items

fruits = ["apple", "banana", "orange", "grape"]

print(fruits[0])    # "apple"
print(fruits[-1])   # "grape" (last item)
print(fruits[1:3])  # ["banana", "orange"] (slicing)
print(fruits[::-1]) # reversed list

Modifying Lists

fruits = ["apple", "banana", "orange"]

# Change an item
fruits[1] = "blueberry"
print(fruits)  # ["apple", "blueberry", "orange"]

# Add items
fruits.append("grape")       # Add to end
fruits.insert(1, "mango")    # Insert at index 1
print(fruits)

# Remove items
fruits.remove("apple")       # Remove by value
last = fruits.pop()          # Remove and return last
first = fruits.pop(0)        # Remove and return first
del fruits[0]               # Delete by index
fruits.clear()               # Remove all items

List Methods

numbers = [3, 1, 4, 1, 5, 9, 2, 6]

numbers.sort()           # Sort in place
print(numbers)           # [1, 1, 2, 3, 4, 5, 6, 9]

numbers.reverse()        # Reverse in place
print(numbers)           # [9, 6, 5, 4, 3, 2, 1, 1]

print(len(numbers))      # 8 (number of items)
print(max(numbers))      # 9
print(min(numbers))      # 1
print(sum(numbers))      # 31
print(numbers.count(1))  # 2 (how many times 1 appears)
print(5 in numbers)      # True (check if exists)

List Operations

# Concatenation
a = [1, 2, 3]
b = [4, 5, 6]
c = a + b
print(c)  # [1, 2, 3, 4, 5, 6]

# Repetition
d = [0] * 5
print(d)  # [0, 0, 0, 0, 0]

# Unpacking
first, second, third = [10, 20, 30]
print(first, second, third)  # 10 20 30

Tuples

Tuples are like lists but immutable — you cannot change them after creation. Use parentheses ():

# Creating tuples
point = (3, 4)
colors = ("red", "green", "blue")
single = (1,)  # Comma needed for single-item tuple

# Accessing (same as lists)
print(point[0])   # 3
print(point[-1])  # 4

# Tuple unpacking
x, y = point
print(f"x={x}, y={y}")

# Cannot modify!
# point[0] = 5  # TypeError!

# Why use tuples?
# - Faster than lists
# - Used as dictionary keys
# - Data that shouldn't change

When to Use Lists vs Tuples

  • Lists: when you need to add, remove, or change items
  • Tuples: when data should not change (coordinates, return values, constants)

Lists with Different Types

student = ["Alice", 25, 3.8, True]
name, age, gpa, is_enrolled = student
print(f"{name} is {age}, GPA: {gpa}")
