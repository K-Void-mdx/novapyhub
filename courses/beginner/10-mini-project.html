Lesson 10: Mini Project — Build a Calculator

Project Overview

In this lesson, you'll build a fully functional command-line calculator. This project brings together everything you've learned: variables, conditionals, loops, functions, error handling, and user input.

What We're Building

A calculator that:

  • Supports addition (+), subtraction (-), multiplication (*), division (/)
  • Handles invalid input gracefully
  • Lets the user continue or exit
  • Displays a clean, user-friendly interface

Step 1: Basic Structure

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "Error: Division by zero!"
    return a / b

Step 2: Display Menu

def show_menu():
    print("\n" + "="*30)
    print("    NOVA PY-HUB CALCULATOR")
    print("="*30)
    print("1. Add (+)")
    print("2. Subtract (-)")
    print("3. Multiply (*)")
    print("4. Divide (/)")
    print("5. Exit")
    print("="*30)

Step 3: Get User Input

def get_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("Invalid input! Please enter a number.")

Step 4: Main Program Loop

def main():
    while True:
        show_menu()
        choice = input("Choose an option (1-5): ")

        if choice == "5":
            print("Thank you for using Nova Py-Hub Calculator!")
            print("Goodbye!")
            break

        if choice in ("1", "2", "3", "4"):
            num1 = get_number("Enter first number: ")
            num2 = get_number("Enter second number: ")

            if choice == "1":
                result = add(num1, num2)
                operation = "+"
            elif choice == "2":
                result = subtract(num1, num2)
                operation = "-"
            elif choice == "3":
                result = multiply(num1, num2)
                operation = "*"
            elif choice == "4":
                result = divide(num1, num2)
                operation = "/"

            print(f"\n{num1} {operation} {num2} = {result}")
        else:
            print("Invalid choice! Please select 1-5.")

if __name__ == "__main__":
    main()

def multiply(a, b): return a * b
def divide(a, b):

    return a / b

def show_menu():
    print("\n" + "="*30)
    print("    NOVA PY-HUB CALCULATOR")

    print("1. Add (+)")
    print("2. Subtract (-)")

def get_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:

def main():
    while True:
        show_menu()

            print("Goodbye!")
            break
        if choice in ("1", "2", "3", "4"):
            num1 = get_number("Enter first number: ")

            print("Invalid choice! Select 1-5.")

if __name__ == "__main__":
    main()

Challenge Extensions

Once your basic calculator works, try adding:

  • Power/exponent — add option 6 for ^
  • Modulo (remainder) — add option 7 for %
  • Calculation history — store results in a list and show them
  • Colorful output — use ANSI escape codes for colored text
  • Save to file — log all calculations to a file

What You've Learned

Congratulations! By building this calculator, you've used:

  • Functions to organize code
  • Conditionals (if/elif/else) for menu choices
  • Loops (while True) for the main program
  • Try/except for error handling
  • Dictionaries for clean operation mapping
  • User input with input()
  • The if __name__ pattern
