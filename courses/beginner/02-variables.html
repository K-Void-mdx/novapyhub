Lesson 2: Variables and Data Types

What is a Variable?

A variable is a container for storing data. Think of it as a labeled box where you put a value. In Python, you create a variable by giving it a name and assigning a value with =:

name = "Alice"
age = 25
height = 5.6
is_student = True

Basic Data Types

Python has several built-in data types:

Type Example Description
int 42 Whole numbers
float 3.14 Decimal numbers
str "Hello" Text (strings)
bool True / False Boolean (true/false)
NoneType None Represents "no value"

Checking Types

Use type() to check the data type of any value:

print(type(42))        # 
print(type(3.14))      # 
print(type("Hello"))   # 
print(type(True))      #

Variable Naming Rules

  • Names can contain letters, numbers, and underscores
  • Names cannot start with a number
  • Names are case-sensitive (age and Age are different)
  • Use descriptive names: student_name not sn
  • Use lowercase with underscores (snake_case) by convention
# Good variable names
first_name = "David"
total_score = 95
is_logged_in = False

# Bad variable names
x = "David"       # Not descriptive
1st_place = "Ali"  # Starts with number (ERROR)
class = "Math"     # Reserved keyword (ERROR)

Type Conversion

You can convert between types using conversion functions:

# String to int
age_str = "25"
age_int = int(age_str)     # 25 (integer)

# Int to string
score = 95
score_str = str(score)     # "95" (string)

# String to float
pi_str = "3.14"
pi_float = float(pi_str)   # 3.14 (float)

# Int to float
x = 10
y = float(x)               # 10.0 (float)

Dynamic Typing

Python is dynamically typed — a variable can change type:

value = 42          # value is an int
print(type(value))

value = "Now I'm text"  # value is now a string
print(type(value))

value = 3.14        # value is now a float
print(type(value))

Practice Exercises

  1. Create variables for your name, age, height, and whether you're a student
  2. Print each variable along with its type using print() and type()
  3. Convert your age (int) to a string and print "I am X years old" using it
  4. Try creating variables with invalid names and see the error messages
