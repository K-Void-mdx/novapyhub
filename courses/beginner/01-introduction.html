Lesson 1: Introduction to Python

What is Python?

Python is a high-level, interpreted programming language created by Guido van Rossum in 1991. It is known for its readability and simplicity — often described as "executable pseudocode." Python is used everywhere: web development, data science, artificial intelligence, automation, and more.

Why Learn Python?

  • Easy to read and write — Python's syntax is clean and intuitive
  • Huge community — millions of developers, endless resources
  • Versatile — web, data, AI, games, automation, and more
  • Job opportunities — one of the most in-demand skills
  • Free and open source — zero cost to start

Installing Python

Before writing Python code, you need Python installed. Here's how:

On PC (Windows/Mac/Linux)

Go to python.org and download the latest version. Run the installer and check "Add Python to PATH" during installation. Verify installation by opening a terminal/command prompt and typing:

python --version

On Phone (Android)

Install Termux from F-Droid (not Google Play — it's outdated). Open Termux and run:

pkg update && pkg upgrade
pkg install python
python --version

On iPhone/iPad

Install Pythonista or Pyto from the App Store. These include a code editor and Python interpreter right on your device.

Your First Python Program

Open a Python REPL (interactive shell) by typing python in your terminal, or create a file called hello.py. Write:

print("Hello, World!")
print("Welcome to Nova Py-Hub!")

Run it with:

python hello.py

Understanding the Code

print() is a built-in Python function that displays output to the screen. The text inside quotes " " is called a string. Python executes code line by line from top to bottom.

Python as a Calculator

Python can do math right away. Try these in the REPL:

>>> 2 + 3
5
>>> 10 - 4
6
>>> 3 * 7
21
>>> 15 / 3
5.0
>>> 2 ** 10
1024
>>> 17 % 3
2

Comments in Python

Comments are notes in your code that Python ignores. Use # for single-line comments:

# This is a comment
print("Hello")  # This is also a comment

Practice Exercises

  1. Print your name and age using print()
  2. Calculate the area of a rectangle (width * height) using Python as a calculator
  3. Use comments to describe what each line of your code does
  4. Print the result of 5 + 3 * 2 — what do you notice?

Key Takeaways

  • Python is a beginner-friendly, powerful programming language
  • You can run Python on PC or phone
  • print() displays output to the screen
  • Python can work as a calculator with standard math operators
  • Comments (#) help document your code
