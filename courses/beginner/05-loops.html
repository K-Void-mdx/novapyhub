Lesson 5: Loops — For and While

Why Loops?

Loops let you repeat code multiple times without writing it over and over. They are essential for working with collections of data.

The for Loop

The for loop iterates over a sequence (list, string, range, etc.):

# Loop through a list
fruits = ["apple", "banana", "orange"]
for fruit in fruits:
    print(f"I like {fruit}")

# Loop through a string
for char in "Python":
    print(char)

The range() Function

range() generates a sequence of numbers:

# range(stop) — 0 to stop-1
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# range(start, stop)
for i in range(2, 7):
    print(i)  # 2, 3, 4, 5, 6

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8

# Counting down
for i in range(10, 0, -1):
    print(i)  # 10, 9, 8, ... 1
print("Blast off!")

Looping with enumerate()

When you need both index and value:

fruits = ["apple", "banana", "orange"]
for index, fruit in enumerate(fruits):
    print(f"{index + 1}. {fruit}")

# Output:
# 1. apple
# 2. banana
# 3. orange

The while Loop

The while loop repeats as long as a condition is True:

# Count from 1 to 5
count = 1
while count <= 5:
    print(count)
    count += 1  # IMPORTANT: don't forget this!

# User input loop
secret = "python"
guess = ""
while guess != secret:
    guess = input("Guess the secret word: ")
print("You got it!")

Warning: Make sure the condition eventually becomes False, or you'll get an infinite loop!

break and continue

break exits the loop immediately. continue skips to the next iteration:

# break — stop the loop
for i in range(10):
    if i == 5:
        break  # Stop when i is 5
    print(i)   # Prints: 0, 1, 2, 3, 4

# continue — skip this iteration
for i in range(10):
    if i % 2 == 0:
        continue  # Skip even numbers
    print(i)      # Prints: 1, 3, 5, 7, 9

# Practical: find first even number
numbers = [3, 7, 9, 12, 15, 18]
for num in numbers:
    if num % 2 == 0:
        print(f"First even: {num}")
        break

The else Clause with Loops

Loops can have an else that runs when the loop finishes normally (not via break):

# else runs when NO break happened
numbers = [1, 3, 5, 7, 9]
for num in numbers:
    if num % 2 == 0:
        print("Found even number!")
        break
else:
    print("No even numbers found.")  # This runs

Nested Loops

Loops inside loops:

# Multiplication table
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i * j}")
    print()  # Blank line after each row

Looping Through Dictionaries

student = {"name": "Alice", "age": 25, "grade": "A"}

# Loop through keys
for key in student:
    print(key)

# Loop through values
for value in student.values():
    print(value)

# Loop through both
for key, value in student.items():
    print(f"{key}: {value}")
